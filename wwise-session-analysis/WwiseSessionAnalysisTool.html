// WHAT THIS TOOL DOES
Analyses profiling sessions from Audiokinetic Wwise and returns aggregated audio performance metrics: CPU usage, active voices, memory, streamsing and loudness. Designed for QA audio on game projects — fast to use, no installation required.
01 //Open Wwise and start a game session connected to the Profiler
02 //In the Performance Monitor, start capture with Start/Stop Capture (Alt+C)
03 //Once capture is complete, right-click on the graph in the Performance Monitor
04 //Seleziona "Save Performance Counters" — salva un file .txt
05 //Drag the .txt file here or click to load it
⚠ Loudness Note — To have loudness data in the exported file, you must explicitly enable Loudness Meter capture in Wwise before starting the session. Go to Profiler → Show Profiler Settings (Alt+G) and make sure Loudness entries are enabled. Without this, loudness columns will be absent or empty in the exported file.

⚠ METHODOLOGICAL NOTE — The integrated loudness value is an approximation computed as the average of Short-term values across the entire session, excluding frames below a gate threshold of approximately −70 LUFS — base behaviour of the ITU-R BS.1770 algorithm. It is not identical to a true integrated value measured in real time by a dedicated loudness meter, but provides a reasonable estimate for QA purposes. For accurate values, use dedicated tools such as a Loudness Meter (es. Youlean, WLM Plus, MeterPlugs).
